# Phase 5. PDF 레드마킹 — `[CLOUD]` 구현 / `[WIN]` 실도면 검증

## 목표
`--redmark` 옵션 시 원본 도면 PDF 위에 **빨간 박스 + 오류 번호**를 자동 기입한 `*_redmark.pdf` 생성.

## 지시
1. `reporter/redmark_pdf.py` (PyMuPDF)
   - 입력: 원본 PDF(경로 B로 매칭했거나 COM으로 내보낸 것) + `Issue[]`
   - `bbox`가 있는 이슈: 사각형(빨강, 선 두께·여백 설정) + 좌상단에 원형 번호 태그(Excel `No`와 동일)
   - `bbox`가 없는 이슈(예: 일반공차 누락): 해당 시트 **타이틀블록 영역 또는 우측 여백**에 번호 목록으로 기입
   - 겹치는 태그 자동 오프셋
   - 마지막 페이지에 "검토 요약" 페이지 추가(옵션)
2. 좌표계
   - 경로 B: PDF pt 그대로
   - 경로 C(SolidWorks 시트 좌표, m, 좌하단 원점): `x_pt = x_m * 1000 / 25.4 * 72`, `y_pt = page_h - y_m*1000/25.4*72` — 시트 크기·회전 반영, 변환 함수 단위 테스트 필수
3. PDF 원본이 없을 때: 경고 후 스킵 (`[WIN]` + `--com`이면 COM으로 PDF 내보내기 후 진행)

## 테스트
- 합성 PDF + 가짜 이슈 → 결과 PDF의 annotation/drawing 개수·위치 검증
- 좌표 변환 왕복 테스트(A3/A1, 가로/세로)
- `[WIN]` 사용자 확인:
  - [ ] 실도면 PDF에서 박스가 해당 치수/노트를 정확히 감싸는가
  - [ ] 번호가 Excel No와 일치하는가

## 완료 기준
- 합성 데이터 테스트 통과 + `[WIN]` 실도면 3종 육안 검증 기록
