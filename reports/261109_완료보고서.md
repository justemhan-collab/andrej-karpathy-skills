## 4. 처리 중 발견·수정 사항

- 공식 설치 프로그램이 impeccable.style 접속 차단으로 실패 → 개인 환경 "han" 허용 호스트에 `impeccable.style` 추가 후 성공
- headless Chromium에서 한글 다운로드 파일명이 "download"로 바뀜 → Excel 파일명을 `YYMMDD_HHMM_drawing-review.xlsx`(ASCII)로 변경
- DXF 입력 시 File 객체 처리 오류, 측정값 없는 DIMENSION 처리 → 수정 후 E2E로 확인

## 6. 알려진 한계

- SLDDRW는 브라우저에서 직접 읽을 수 없음 → PDF 내보내기 또는 Python 추출기 JSON 필요 (Python 추출기는 프롬프트만 작성, 코드 미구현)
